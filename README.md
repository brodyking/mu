<h1 align="center">μ - your personal music library</h1>

<p align="center">
  μ (<code>mu</code>) is an opinionated MacOS and Linux music library management tool designed to be <b>backup friendly</b> and <b>programmable</b>.<br>
  All music is stored in a hierarchical format, and the internal database is a simple SQLite file.</p>

<img src="./.github/images/screenshot.png" alt="Screenshot of muc" width="100%">

<p align="center">
  µ comes with mµc (<code>muc</code>) which is a tui music player that utilizes VLC for audio playback.
</p>

<p align="center">
  To get started with µ, checkout the <a href="./DOCS.md">documentation</a>.
</p>
